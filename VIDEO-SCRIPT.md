# Heartbeat — demo video script (as recorded, 2:10)

Narration is English text-to-speech with burned-in captions. Every on-chain shot is a live explorer page (Blockscout / Reactscan) for a real testnet transaction listed in README.md; cards and stills are rendered from the repository's own evidence, test output and the live status page. No simulated activity is shown as a transaction.

| Time | Shot | Narration |
|---|---|---|
| 0:00–0:19 | Heartbeat · architecture | “Your assets may sit on one chain while your life happens on others. Heartbeat watches your activity on Base Sepolia and Ethereum Sepolia through a Reactive contract on Lasna. If you go quiet everywhere, it warns you, and after a grace period your vault goes to the person you chose.” |
| 0:19–0:38 | Deployed contracts and policy | “This vault holds one hundred demo tokens for a separate beneficiary wallet. You don't need a special button to stay alive: an ordinary transfer of a token you chose, here WETH, counts. Incoming and zero-value transfers are ignored, so nobody else can keep the vault alive for you.” |
| 0:38–0:51 | Base Sepolia · ordinary WETH transfer from the owner / Lasna · Reactive contract counts it as activity / Base Sepolia · heartbeat callback to the vault | “The owner sends some WETH on Base Sepolia. Reactive Network delivers that transfer to the contract on Lasna, which sends an authenticated heartbeat to the vault. No keeper is running.” |
| 0:51–1:06 | Status page · warning / Alert delivered via ntfy | “Then silence. Network cron on Lasna checks the clock, and after four quiet minutes the vault emits a warning. The status page turns amber and shows the release countdown, and the notifier pushes the warning to your phone.” |
| 1:06–1:15 | Ethereum Sepolia · owner answers with a transfer / Base Sepolia · heartbeat clears the warning | “The owner sees it and answers with a WETH transfer on Ethereum Sepolia. The warning is cleared on Base within seconds.” |
| 1:15–1:29 | Base Sepolia · owner cancels / Lasna · policy off, cron unsubscribed | “Going travelling? Cancel pauses the policy, and the Reactive contract unsubscribes from cron so a paused policy costs nothing. Reconfiguring turns it back on with a new epoch, and stale callbacks are ignored.” |
| 1:29–1:47 | Base Sepolia · release: 100 HBA to the beneficiary / Lasna · release acknowledged, everything unsubscribed / Status page · released | “After the new policy runs out, eight quiet minutes and a minute of grace after its warning, the vault releases all one hundred tokens to the beneficiary. The acknowledgement on Lasna unsubscribes cron and every activity source, and the owner withdraws the unused fees.” |
| 1:47–1:59 | Tests, review regressions and a deliberate mutation | “Before deploying, a fresh review found that a zero-value transfer could fake activity. It is fixed, and the counterexample stays in the suite: put the bug back and the test fails.” |
| 1:59–2:10 | README · github.com/boowenchen/reactive-heartbeat | “Heartbeat is an inactivity policy, not proof of death. The code, the status page, the notifier and the full transaction trail are public on GitHub.” |
