Vault

What keeps it alive

Only activity from the owner address counts. Anything else is ignored.

    Owner controls

    I’m alive

    Sends a small transaction to a Pulse contract (it only records an event). It resets the countdown only when it comes from the owner address; from any other address it changes nothing. The vault learns about it through the Reactive network, so allow a short delay.

    Cancel

    Turns the release off immediately. Nothing is sent to the beneficiary while it is cancelled. Owner only, on the vault’s chain.

    Reconfigure

    Sets a new beneficiary and timing, turns the vault on and restarts the countdown from now. Owner only. Not possible after a release.

    Warn after = silence before a warning. Release after = silence before tokens can move. Grace = minimum time between the warning and the release. Release after must be longer than warn after.

    Take the tokens back

    The vault is cancelled and still holds tokens. This sends all of them to the owner address.
